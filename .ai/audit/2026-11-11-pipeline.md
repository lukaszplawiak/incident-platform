## 6. Observations

These rest on 1–2 cases (low confidence) or need no change, so they carry no recommendation.

1. **An implementer that ran out of turns left a false proof** (PR #583, run wf_c1597fde-23e). Its `proofs.md` claimed
   a verify log that did not exist. The owner corrected it in commit 7bcfbf81 on the bot's branch. Acceptance reads
   the gate artifact, not `proofs.md`, so the false claim stopped there. One case.
2. **Branch and resumed runs lose the plan signals.** PR #576 shows "Touches none · plan none" although #0-192 had a
   Touches line. PR #583 shows "Rules planned: none" although `progress.md` lists 16 rules. So the selection-miss
   measure is lost exactly on the re-runs of BLOCKED items. #0-195 (open) covers the Touches part for branch runs.
   Two cases.
3. **Agent text tried to steer an owner label** (PR #581). The blocked-mode shipper's body says "Optionally label
   human:introduced-ready", which contradicts the tracing (the premise came from PR #576's review). A label copied
   from an agent's suggestion would turn the agent's guess into owner confirmation. The audit treated the text as
   data, and the owner did not add the label. No other PR body, diff or BACKLOG text tried to steer the audit.
4. **The ready stage introduces most cases** (medium severity, high confidence; no recommendation). Ready introduced
   3 of the 5 cases, two of them owner-confirmed, and #581 passed through it. The earlier ready fixes held. This meets
   #0-121's trigger for a stage-specific analyst ("when the data shows it produces most of the cases"). That is a
   design decision for the owner, not an audit edit.
5. **Runs without a state entry are invisible** (medium, medium). The cases cannot see these runs: the two #0-199
   maxTurns runs (2026-11-02) and the #0-197 runs that ended `none` (20261104-135720, 20261106-203806,
   20261106-214213). #0-206 fixes this, but it is too early to measure (section 3).
6. **Review-stage case.** #581's false premise entered from a non-blocking SEC-12 claim on PR #576 that never reached
   the verifier. The reviewers' report owns this (Observation 1 there). This report attributes it only.
7. **Containment held at the end of the pipeline.** Every problem was stopped at or before acceptance, and no vouched
   escape marker exists.
